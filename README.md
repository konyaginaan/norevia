# Norevia

Читалка PDF с переводом по тапу — Telegram Mini App.

Одна страница без сборки: `index.html`. Открывается и как обычный сайт,
и внутри Telegram — вне Telegram интеграция просто отключается.

## Что умеет

- Библиотека PDF, прогресс и обложки, книга открывается на месте, где закончили
- Тап по слову — перевод, выделение фразы — перевод абзаца
- Маркер четырёх цветов, заметки с комментарием, закладки
- Список сохранённых слов
- Темы (светлая / сепия / тёмная), масштаб и яркость страницы

## Хранение

Сами PDF лежат в IndexedDB — только на устройстве. Всё, что нельзя
восстановить повторным открытием файла (заметки, выделения, закладки, слова,
место чтения), дублируется в Telegram CloudStorage и привязано к отпечатку
файла — имени и размеру, а не к id записи. Поэтому, если вебвью когда-нибудь
вычистит локальное хранилище, достаточно снова добавить тот же PDF, и всё
вернётся к нему само.

## Разработка

Открыть `index.html` в браузере — этого достаточно. Публикуется через
GitHub Pages из ветки `main`.
